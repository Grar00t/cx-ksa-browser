# Security Policy

## Reporting
Please report suspected vulnerabilities responsibly through a private channel
rather than a public issue whenever disclosure could expose users or secrets.

Do not post API keys, tokens, credentials, private URLs, personal data,
exploit payloads, or other secrets in GitHub issues or discussions.

## Project posture
Agent and MCP capabilities must remain local-first, consent-based, allowlisted,
and restricted by default.

Security claims are only considered verified when supported by executed tests,
inspection, or reproducible evidence.
